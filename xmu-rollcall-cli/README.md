# XMUCS Check-in CLI

本目录为 CLI 源码，基于 [KrsMt-0113/XMU-Rollcall-Bot](https://github.com/KrsMt-0113/XMU-Rollcall-Bot) 3.4.1 修改，接口适配参考 [alkali210/XMU-Rollcall-Bot](https://github.com/alkali210/XMU-Rollcall-Bot)。保留原作者 MIT 许可证与版权声明。

请优先在仓库根目录执行 `python3 run.py`，使用已包含依赖的当前修复版；完整使用说明、修改范围和限制见 [仓库 README](../README.md)。

从本目录安装源码可运行 `python3 -m pip install .`，随后使用 `xmu config` 和 `xmu start`。iPhone a-Shell mini 请使用仓库根目录入口，以采用包内纯 Python 加密依赖。

已有 PyPI 包的版本号仍是 3.4.1，不包含本仓库的本地修改。直接从 PyPI 安装不能代替本仓库的修复版。
